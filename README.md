# TerraMind ML

An ML and MLOps platform for extreme rainfall risk prediction
and climate anomaly detection.

## Objectives

- Build a reproducible climate data pipeline.
- Train and compare supervised ML models.
- Detect unusual climate observations using GMM and other methods.
- Track experiments and model versions using MLflow.
- Serve predictions through FastAPI.
- Visualize results and model health using Streamlit.

## Technology Stack

Python, Pandas, NumPy, Scikit-learn, MLflow, FastAPI, Streamlit.

## Data

The project will use documented, real climate datasets.
Data provenance, units, preprocessing, and target definitions
will be recorded during development.
